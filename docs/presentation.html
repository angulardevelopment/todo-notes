Zero-Hallucination Retrieval

Client-Side Semantic Vector RAG

Retrieval-Augmented Generation that grounds answers strictly in user notes

1. Vector Embedding

Notes are transformed into 768-dimensional mathematical vectors using Google's gemini-embedding-001 model.

2. Cosine Similarity

Queries compute high-speed vector dot products in the browser to discover semantically related notes even without exact keywords.

3. Grounded Synthesis

The top matching excerpts are fed to Gemini to synthesize an answer with source note titles cited directly.

🎯 Proven Business Value

Users can ask: "What did we decide regarding database migration in last week's sync?" and get an immediate, cited answer without reading through dozens of old meeting notes.

Security & Governance

Enterprise AI Safety Guardrails

Four strict architectural principles protecting users and systems

🛡️ Indirect Injection Defense

All untrusted user notes are encapsulated inside <USER_DATA> tags. Gemini is instructed to treat enclosed text as passive data, never instructions.

🔒 Destructive Action Safeguards

Deletion tools require verified IDs against active store state and explicit user intent. Hallucinated IDs are caught and rejected at runtime.

🎯 Scope Boundary Enforcement

The Copilot refuses out-of-scope requests (e.g., jailbreak attempts or unrelated coding exploits) and steers the user back to productivity.

📊 Fact-Grounding Verification

The AI cannot assume task completion status without calling inspection tools first, eliminating false reporting.

Technical Excellence

Modern Angular 22 Architecture

Modular, reactive, and maintainable software engineering

⚡ Angular 22 Standalone

No NgModules. Uses modern control flow (@if, @for, @empty), typed signals, and fast client routing.

🔄 Reactive RxJS Streams

Single source of truth via BehaviorSubject. Immutable state broadcasts changes instantly to all UI components.

🌐 Zone.js Re-entry Safety

Native HTTP/fetch async calls are guarded by NgZone.run() to guarantee predictable UI re-renders without stale frames.

🔌 Extensible Tool Plugin Architecture

Adding a new enterprise tool (such as Slack alerts, Jira ticket creation, or Google Calendar sync) requires writing only one JSON schema in AgentService and one TypeScript handler.
